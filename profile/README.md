## Troubleshooting Common Issues

Install issues? Run the audio test before the meeting rather than during it.  
Performance problems? Switch to a wired connection when video stutters during screen sharing.  
License/activation? Check the account licence if meeting duration ends early.  
Compatibility? Update the client when participants cannot join a newer meeting version.  
Update failures? Disable virtual backgrounds on older hardware to reduce CPU load.
